## Ce que présente le site

- **Mémoire de Master : DriftGuard**, une plateforme de détection et de gestion automatisée du data drift (FastAPI, React, Evidently AI, MLflow, Render).
- **Cinq projets** avec leur code sur GitHub : DriftGuard, DiabèteScore, Dashboard Power BI, API Churn et Pipeline Churn.
- Expériences, parcours, compétences et deux versions du CV (analyste de données, développeuse fullstack).
- Version française et anglaise, thème clair et sombre, affichage adapté au mobile.

## Structure

| Fichier | Rôle |
|---|---|
| `index.html` | La page du portfolio (contenu, style et script dans un seul fichier) |
| `404.html` | Page affichée quand une adresse n'existe pas |
| `assets/` | Photos, capture du dashboard, image d'aperçu et icônes |
| `cv/` | Les deux versions du CV en PDF |
| `robots.txt`, `sitemap.xml` | Référencement par les moteurs de recherche |

## Modifier le contenu

Tout le contenu se trouve en bas de `index.html`, dans deux blocs :

- `PROFIL` : nom, photos, e-mail, téléphone, WhatsApp, liens GitHub et LinkedIn, CV.
- `TEXT` : tous les textes, en français (`fr`) et en anglais (`en`), y compris la liste des projets et des expériences.

Pour ajouter un projet, copiez une ligne de la liste `projects` dans les deux langues et adaptez le titre, le chiffre clé, la description et le lien.
